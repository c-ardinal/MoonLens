# 言語ファイル

UI 文言の訳文。1 言語 1 ファイル（`<言語コード>.json`）、画面側（`src/`）と Rust 側（`src-tauri/src/`）の共用。
ビルド時に本フォルダーの全ファイルをアプリへ組込み。

## 構成

- 原文は日本語。ソース中の日本語文言が検索キー、値が訳文。日本語用のファイルは不要。
- `@language`：当該言語での言語名（例：`English`）。設定画面「表示言語」の選択肢に表示。
- `{name}`：値の埋込み箇所。訳文にも同一の名称で記述（語順の変更は可能）。
- `原文#文脈`：同一原文の訳し分け（例：`翻訳#action`）。`#文脈` は表示対象外。
- 項目は符号位置順（`npm run lint:i18n -- --fix` で自動整列）。

```json
{
  "@language": "English",
  "保存": "Save",
  "{n} 件": "{n} items",
  "翻訳#action": "Translate"
}
```

## 言語の追加

1. `en.json` を複製し、ファイル名を言語コード（例：`fr.json`、OS の言語コードの先頭部分と同一）へ変更。
2. `@language` と全項目の値を翻訳。
3. `npm run lint:i18n` で過不足を確認。

ソースの変更は不要。設定画面の選択肢と「自動（OS の言語）」の判定へ自動で反映。
OS の言語に該当するファイルが無い環境は英語で表示。

## 文言の追加・変更

ソースへ日本語で記述（画面側：`t('…')`、Rust 側：`tr!("…")`）し、全言語ファイルへ訳文を追加。
未登録・未使用の項目は `npm run lint:i18n` が検出（CI で毎回実行）。規約：`CLAUDE.md`「表示言語」。
