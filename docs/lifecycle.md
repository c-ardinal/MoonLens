# ライフサイクル別ケース表

MoonLens の導入〜削除の各段階で発生するケースと、期待動作・実動作の一覧。
機能・設定の追加時は、該当段階の行を追加・更新する。

- **期待動作**：ユーザーにとって「想定外」とならない挙動。
- **状態**：`OK`＝確認済み／`修正`＝本表作成時に不一致を発見し修正済み／`要実機`＝CI・コンテナで再現不可（実機確認待ち）／`既知`＝未対応（理由を記載）。
- **確認**：自動テスト名、または手動確認の方法。

前提：全処理ローカル実行。ネットワーク通信はモデルのダウンロード、ユーザーの明示操作によるリンク起動のみ。

## 既知の課題（本表作成時点）

- **ライブ字幕の遅延（GPU なし）**：既定の Whisper large-v3-turbo は毎回 30 秒の区間を処理するため、CPU のみでは 1 チャンクの認識に数秒〜十数秒を要する（4 コアのクラウド VM で約 15 秒）。音声の欠落はないが、字幕は遅延する。GPU（Metal／Vulkan／CUDA）では大幅な短縮を想定（未計測）。低速 PC 向けに Whisper small（約 3 倍速、日本語の精度は低下）を用意。詳細は [asr-models.md](asr-models.md)。
- **DirectML の実機未計測**：DirectML による文字認識は Windows CI（GPU なし、ソフトウェア描画）での動作と認識結果の一致のみ確認。実機 GPU での速度は未計測（自動選択は実測に基づくため、CPU より低速な環境では CPU を採用）。macOS の GPU（CoreML）は未対応。
- **ocrs モデルの整合性検証なし**：PP-OCRv5 と LLM はハッシュ固定だが、ocrs（英語のみの予備エンジン）は配布元がハッシュを公開していない。
