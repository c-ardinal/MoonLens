# 音声認識モデルの選定（2026-11）

ライブ字幕の音声認識は、アプリに内蔵した whisper.cpp（`src-tauri/vendor/whisper.cpp`）で実行する。
本書は既定モデルを選んだ計測の方法と結果をまとめたもの。翻訳モデルと同じく、
**品質を落とさずに、一般的な PC で実用になる速さ**を基準に選ぶ。

## 結論

| 用途 | モデル | ファイル |
| --- | --- | --- |
| **既定** | **Whisper large-v3-turbo**（q8_0） | `ggml-large-v3-turbo-q8_0.bin`（874 MB） |
| 低スペック PC 向け | Whisper small（q5_1） | `ggml-small-q5_1.bin`（190 MB） |

- large-v3-turbo は日本語の文字誤り率が small の約半分。英語は両者とも良好で、差は小さい。
- 同じ large-v3-turbo でも q8_0 は q5_0 より **CPU で速く**（約 25%）、精度も同等以上。既定は q8_0 とした。
- small は約 3 倍速いが、日本語の固有名詞・同音異義語の誤りが目立つ（「地殻」→「近く」、「溶岩」→「王岩」など）。
- base は日本語の文字誤り率が 20% を超え、字幕として読めないため採用しない。
- 配布元は whisper.cpp の Hugging Face リポジトリ（`ggerganov/whisper.cpp`）。サイズと SHA-256 で固定している（`whisper_models.rs`）。モデルの重みは MIT License（OpenAI Whisper）。

## 方法

- **実行環境**: クラウドの x86 CPU 4 コア（AVX-512、GPU なし）、RAM 15 GB。アプリと同じコード（`cargo run --example asr_bench`）で、`n_threads=4`、greedy、言語指定あり。
- **データ**: FLEURS テストセットの日本語・英語から、重複のない文を各 30 文（1 文 10〜20 秒）。
- **指標**: 日本語は文字誤り率（CER、句読点・空白を除去して比較）、英語は単語誤り率（WER、小文字化・記号除去）。英語の誤りの多くは数字表記の違い（「one-hundred percent」→「100%」）で、意味の誤りではない。
- **速度**: 1 文あたりの認識時間の中央値（モデル読込を除く）。Whisper は音声の長さに関係なく 30 秒の窓を毎回処理するため、文の長さによらずほぼ一定になる。

## 結果

| モデル | 日本語 CER | 英語 WER | 1 回の認識（中央値） | ファイル |
| --- | ---: | ---: | ---: | ---: |
| **large-v3-turbo q8_0** | **5.8%** | **7.2%** | 14.7 s | 874 MB |
| small q5_1 | 11.8% | 7.9% | 4.8 s | 190 MB |

予備計測（各 8 文、日本語）：large-v3-turbo q8_0 は CER 3.2%・14.3 s、q5_0 は CER 3.2〜3.5%・16.4〜18.9 s、small は 10.2%・4.9 s、base は 22.3%・1.2 s。

## リアルタイム性

- 4 コアの VM では large-v3-turbo の 1 回の認識に約 15 秒かかる。一般的な 8 コア以上のデスクトップ CPU では数秒、GPU（macOS の Metal、Windows / Linux の Vulkan、CUDA）では 1 秒未満を見込む（GPU は未計測）。
- 認識が音声に追いつかない場合でも音声は捨てない。溜まった音声は次の 1 回でまとめて認識する（最大 28 秒）。Whisper の処理量は窓の長さで決まるため、まとめても 1 回あたりの時間はほぼ増えない。遅い PC では字幕が遅れるが、内容は欠けない。
- whisper.cpp の `audio_ctx`（窓を短くして高速化する設定）も試したが、短い発話で幻聴や空出力が出て精度が大きく落ちたため使わない。
- 音声の言語が「自動判定」の場合、判定のたびに処理時間が倍になるため、判定は数チャンクに 1 回とし、間は直前の結果を使う。

## 再現

```sh
cd src-tauri
cargo run --release --example asr_bench -- --model whisper-large-v3-turbo --lang ja a.wav b.wav …
```

モデルはアプリの設定「モデル」からダウンロードしておく。WAV は 16 kHz モノラル（PCM16 または float32）。
