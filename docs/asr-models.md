# 音声認識モデルの選定（2026-11）

ライブ字幕の音声認識は、アプリ内蔵の whisper.cpp（`src-tauri/vendor/whisper.cpp`）で実行する。
本書は既定モデル選定時の計測方法と結果の記録。翻訳モデルと同様に、
**品質を維持しつつ、一般的な PC で実用的な速度**を選定基準とする。

## 結論

| 用途 | モデル | ファイル |
| --- | --- | --- |
| **既定** | **Whisper large-v3-turbo**（q8_0） | `ggml-large-v3-turbo-q8_0.bin`（874 MB） |
| 低スペック PC 向け | Whisper small（q5_1） | `ggml-small-q5_1.bin`（190 MB） |

- large-v3-turbo の日本語の文字誤り率は small の約半分。英語は両者とも良好で、差は僅少。
- 同じ large-v3-turbo でも、q8_0 は q5_0 と比較して **CPU 上で約 25% 高速**、精度も同等以上。よって既定は q8_0。
- small は約 3 倍高速だが、日本語の固有名詞・同音異義語の誤認識が顕著（「地殻」→「近く」、「溶岩」→「王岩」など）。
- base は日本語の文字誤り率が 20% 超で、字幕として判読困難なため不採用。
- 配布元は whisper.cpp の Hugging Face リポジトリ（`ggerganov/whisper.cpp`）。サイズと SHA-256 で固定（`whisper_models.rs`）。モデルの重みは MIT License（OpenAI Whisper）。

## 方法

- **実行環境**：クラウドの x86 CPU 4 コア（AVX-512、GPU なし）、RAM 15 GB。アプリと同一のコード（`cargo run --example asr_bench`）、`n_threads=4`、greedy、言語指定あり。
- **データ**：FLEURS テストセットの日本語・英語から、重複のない文を各 30 文（1 文 10〜20 秒）。
- **指標**：日本語は文字誤り率（CER、句読点・空白を除去して比較）、英語は単語誤り率（WER、小文字化・記号除去）。英語の誤りの大半は数字表記の差異（「one-hundred percent」→「100%」）で、意味上の誤りではない。
- **速度**：1 文あたりの認識時間の中央値（モデル読込を除外）。Whisper は音声長に関係なく毎回 30 秒の区間を処理するため、文の長短による差はほぼ皆無。

## 結果

| モデル | 日本語 CER | 英語 WER | 1 回の認識（中央値） | ファイル |
| --- | ---: | ---: | ---: | ---: |
| **large-v3-turbo q8_0** | **5.8%** | **7.2%** | 14.7 s | 874 MB |
| small q5_1 | 11.8% | 7.9% | 4.8 s | 190 MB |

予備計測（各 8 文、日本語）：large-v3-turbo q8_0 は CER 3.2%・14.3 s、q5_0 は CER 3.2〜3.5%・16.4〜18.9 s、small は 10.2%・4.9 s、base は 22.3%・1.2 s。

## リアルタイム性

- 4 コアの VM では、large-v3-turbo の 1 回の認識に約 15 秒を要する。一般的な 8 コア以上のデスクトップ CPU では数秒、GPU（macOS の Metal、Windows・Linux の Vulkan、CUDA）では 1 秒未満を想定（GPU は未計測）。
- 認識処理が音声入力に追随不可の場合も、音声は破棄しない。未処理の音声は次回に一括認識（最大 28 秒）。Whisper の処理量は区間長で決定するため、一括処理でも 1 回あたりの所要時間はほぼ不変。低速 PC では字幕が遅延するが、内容の欠落はなし。
- whisper.cpp の `audio_ctx`（区間長の短縮による高速化設定）も検証したが、短い発話で幻聴・空出力が発生し精度が大幅に低下したため不採用。
- 音声の言語が「自動判定」の場合、判定はチャンク単位で毎回実行。直前の判定結果を後続チャンクへ流用すると、英語の講演に日本語が一言混在しただけで後続の英語まで日本語として出力されるため不採用。判定用のエンコード結果を認識本体で再利用し（`src-tauri/vendor/whisper.cpp/moonlens.patch`）、判定の追加負荷はデコーダー 1 ステップのみ。

## 再現手順

```sh
cd src-tauri
cargo run --release --example asr_bench -- --model whisper-large-v3-turbo --lang ja a.wav b.wav …
```

事前にアプリの設定「モデル」からモデルを導入。WAV は 16 kHz モノラル（PCM16 または float32）。
