# Phase 25 v2 Embedded LLM 翻訳品質レビュー

ベンチ環境: i5-8400 + RTX 4080 (Vulkan), `MOONLENS_GPU_LAYERS=99`, 5 samples / tier, **few-shot (en→ja 2 例) + 強化システムプロンプト適用後**。

レポート対象: `2026-05-12-phase25b-fewshot-12tiers.md` の per-sample 出力を、ユーザー基準「翻訳前の単語残り (= 未翻訳カタカナ) は許容、単語の置き換え (= 狐→犬など) は危険」で再評価。

## 採点記号

| 記号 | 意味                                                                                                  |
| :--: | ----------------------------------------------------------------------------------------------------- |
|  ✅  | クリーン: 自然な日本語、単語の置換も意味破綻もなし                                                    |

## 推奨

### 採用 (危険度0、品質最高)

- **Compact 帯**: 該当なし — 軽量帯では危険度0かつ速度150+ のチャンピオン不在。Compact+ (Qwen 3 0.6B) が現状ベスト (🚫1)。
- **Standard 帯**: **JA-Standard+ (llm-jp 3.1 1.8B)** — 完璧かつ最速、サイズも 1.1GB に収まる
- **Edge 帯**: **Edge (Gemma 4 E2B)** または **Edge+ (Gemma 4 E4B)** — どちらも完璧

### 不採用 (危険度3、ユーザー基準で却下)

- **Compact++ (Qwen 3.5 0.8B)**: 5/5 中 3/5 で単語誤り発生、軽量帯の他の候補と比べて明確にリスク高

### 微妙 (危険度1、用途次第)

- **Standard++ (Qwen 3.5 2B)**: 1 件のみ単語誤りで Standard+ (Qwen 3 1.7B) より JA 自然度高い。ただし JA-Standard+ (1.8B) が完全上位互換なので存在意義は薄い。
- **Quality-- (Qwen 3.5 4B)**: 同じく 1 件。Edge+ (E4B) が同サイズ帯で完全上位互換。

### 淘汰候補 (危険度0だが他で代替可能)

- **Quality- (Qwen 3 4B 2507)**: Edge (E2B) より遅く品質も微妙、サイズも近い
- **Quality (Qwen 2.5 7B)**: Edge+ (E4B) より遅く品質も劣る、容量だけ大きい
