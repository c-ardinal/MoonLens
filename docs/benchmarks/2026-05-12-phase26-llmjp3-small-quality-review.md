# Phase 26 v2: llm-jp 3 小型バリアント (150M/440M/980M) 翻訳品質レビュー

ベンチ環境: i5-8400 + RTX 4080 (Vulkan), `MOONLENS_GPU_LAYERS=99`, 5 samples/tier, **few-shot (en→ja 2 例) + 強化システムプロンプト適用後**。

レポート対象: 新規 6 ティア (`llm-jp 3 150m/440m/980m` × `base/instruct2`) + 既存 `980m-instruct3` の品質判定。

## 採点記号 (Phase 25 と同じ基準)
- ✅ クリーン: 自然な日本語、単語の置換・意味破綻なし
- ⚠️ 許容範囲: 未翻訳のカタカナ転写・英単語残り・誤字・部分欠落
- 🚫 **危険**: 単語の取り違え、外国語混入、意味破綻、原文無視

## 採用判断

### 採用
- **JA-Compact (980M Instruct3)** — 既存採用済み、品質維持
- **JA-Compact (980M Instruct2)** — 新規採用候補、Instruct3 と同等品質、locally-converted で別の GGUF 経路

### 不採用 (品質不足)
- **JA-Tiny (150M base / Instruct2)** — 翻訳タスク不能、危険度 5
- **JA-Tiny+ (440M base / Instruct2)** — 翻訳指示無視、危険度 5
- **JA-Compact (980M base)** — Instruct 経由でない分明確に劣る、英語出力ケースあり

### サイズ別教訓
| サイズ | 翻訳実用性 | 備考 |
|---|---|---|
| 150M | ❌ | instruction-following 不能 |
| 440M | ❌ | リピートループ、英語そのまま |
| 980M base | ⚠️ | Instruct 経由必須 |
| 980M Instruct | ✅ | 翻訳タスク成立、軽量 GGUF |
| 1.8B Instruct | ✅✅ | より自然な訳語選択 |

## 次のアクション

不採用 5 ティア (150M×2, 440M×2, 980M base) を registry から削除し、980M Instruct2 と Instruct3 のどちらか 1 つを残す形に集約することを推奨。**Instruct3 は mmnga 公式 GGUF (configuration drift リスクなし)、Instruct2 は locally-converted (我々の SP synthesis 経路依存)** なので、後者は配布時のリスクが高い。
