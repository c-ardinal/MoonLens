- Translations are now cached on disk per app: text seen before (menus, item names, repeated lines) appears instantly without a model request, also after restarting MoonLens. Entries are replaced automatically when the translation model, style, or a glossary term that occurs in the text changes, so cached output never overrides a newer setup. Settings → System → Performance shows the cache size and clears it (all, or one app); "訳文キャッシュ保存" turns on-disk caching off.
