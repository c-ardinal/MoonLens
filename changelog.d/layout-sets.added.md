- Layout sets: save the window translation windows that are open (count, position, size, target language, reading mode, view state, and the app window each one is attached to) under Settings → 翻訳 → 配置セット or from the command palette, and restore them later. A set belongs to the app its windows are attached to; one set per app is restored automatically when that app starts, without taking focus, and its windows close again when the app exits. Attached windows are restored relative to the app window, so a set still fits when the app opens elsewhere or at another size.
