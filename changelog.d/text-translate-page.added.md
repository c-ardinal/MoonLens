- Text translation page (menu "翻訳", command palette "テキスト翻訳"):
  source / result panes, language pair with swap, Ctrl+Enter, opt-in
  auto-translate, copy. Multi-line input is translated line by line so
  logs and code keep their structure (blank, log and punctuation-only
  lines are kept as is, indentation is restored), and every line is
  sent with the lines already translated as context, which the
  built-in PLaMo engine reads. Results are saved to history.
