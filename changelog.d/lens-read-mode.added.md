- Window translation: reading mode per window, switched from the
  title bar. "Subtitle" (default) waits until a line that is typed out
  is complete before translating it, and translates each line with the
  lines read before it as context (pronouns and omitted subjects follow
  the dialogue). "UI" translates every reading by itself, for menus and
  labels. A window opened from another window starts in the same mode.
