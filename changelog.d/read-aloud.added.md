- Read aloud: translations can be spoken with the speech synthesis of the OS (Windows: the installed voices, macOS: `say`, Linux: Speech Dispatcher). It runs on the device, downloads no model and does not use the GPU. Turned on per window from the title bar of a translation window or an audio translation window (saved with layout sets), and with a button on the text translation page. Only new translations are spoken; speech that falls behind drops the oldest waiting text. Voice, speed and volume: Settings → 翻訳 → 読上 (`[speech]`).
- Read aloud is silent while an audio translation window listens to the whole PC or the microphone, so MoonLens never transcribes its own speech; choose an application as the audio source to use both.
