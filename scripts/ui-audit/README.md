# UI 監査

共通基盤：`harness.mjs`（ビルド出力の配信・IPC モック・メインウィンドウの全状態の巡回）。

## 4px 格子の監査

`vite build` の出力を IPC モック付きのヘッドレス Chromium で表示し、余白の 4px 格子を実測。
CI（`build.yml` の frontend ジョブ）が毎回実行し、違反 1 件以上で失敗。

```sh
npm run build
npm run audit:grid                                    # 全画面・全文字サイズ
node scripts/ui-audit/grid-audit.mjs build --only lens --json out.json
```

### 対象

| 区分 | 状態 |
| --- | --- |
| メインウィンドウ | ホーム・パレット・テキスト翻訳（結果・通知・右クリックメニュー）・画像翻訳（空・結果）・履歴（音声翻訳の記録・通知・確認）・初期設定・設定の全分類。文字サイズ 5 段 |
| ウィンドウ翻訳 | 幅 700／420／300／200px のタイトルバー・縦メニュー、テキストウィンドウ |
| 字幕ウィンドウ | 停止・待機・認識・字幕表示・エラー |
| 訳文オーバーレイ | 待機・処理中・結果・エラー |

### 規則

| 規則 | 内容 |
| --- | --- |
| `spacing` | padding・margin・gap の表示寸法は 4px の倍数（疑似要素を含む） |
| `offset` | 絶対配置の top／right／bottom／left は 4px の倍数（2px 以下のドット・枠線の補正は対象外） |
| `inline-gap` | 行内配置の文字と要素の間隔は 4px の倍数（空白文字による間隔は不可） |
| `icon-touch` | 図標と文字の間隔は 4px 以上 |
| `glyph-icon` | 記号の字形（▶ 等）を図標として使用不可。図形（`.px-tri`、`Pix.tri`、SVG）へ置換 |
| `v-centre` | 同一行の項目の垂直中心の差は 1px 以内 |
| `box-centre` | 枠付き要素内の文字の上下の余白差は 2px 以内 |
| `block-gap` | 縦積みの要素の間隔は 4px の倍数 |

### 例外の指定

- `data-grid-exempt`：要素と子孫を全規則の対象外へ（スイッチのつまみ等、部品内部の位置合せ）。
- `data-grid-glyph`：記号の字形を本文として許可（キー名の「↑↓」等）。

### 対象外

Canvas 描画（ホームの魔法陣・情報欄、ロゴ、見出し）は DOM の計測対象外。
論理画素（1 ドット＝表示 2px）の偶数指定で 4px 格子へ整列（`src/lib/pixel/home.ts`、`dial.ts`）。
訳文の重畳表示（ウィンドウ翻訳の訳文枠）は原文の位置・寸法へ追従するため対象外。

## 画面超過の監査

メインウィンドウの全状態を文字サイズ 5 段 × ウィンドウ寸法 3 種（既定 1280×800・最小 1120×700・1920×1080）で表示し、
内容の超過を実測。CI が毎回実行し、違反 1 件以上で失敗。

```sh
npm run audit:overflow
node scripts/ui-audit/overflow-audit.mjs build --sizes xlarge --shots out/   # 各状態の画面も保存
```

| 規則 | 内容 |
| --- | --- |
| `h-scroll` | スクロール領域の内容幅が表示幅を超過（横スクロールの発生） |
| `clipped` | 切抜き指定の要素から内容が超過（省略記号・行数制限の指定は対象外） |
| `out-of-view` | ウィンドウ外への突出（縦方向はスクロール領域外の要素のみ） |
| `overlap` | 同一階層の要素の重複 |
| `text-out` | 文字列が親の枠より外へ描画（折返し行の行末空白は許容） |
| `v-scroll` | `data-fit-viewport` の画面（1 画面へ収容する状態）で縦スクロールが発生 |

`data-overflow-exempt`：要素と子孫を対象外へ（収容不可の幅で非表示とする案内文、原文の位置へ追従する訳文の重畳）。

## モック

`mock.json` は IPC の応答表（設定・履歴・モデル一覧）。IPC の追加・変更で画面が空になる場合は更新。
